## 📖 رسالة التطبيق

يهدف تطبيق **"تَسْهِيل"** إلى خدمة طلبة العلم والراغبين في سلوك سبيل التأصيل الشرعي الرصين وفق منهج أهل السنة والجماعة، عبر توفير بيئة تعليمية متكاملة تجمع الشروحات الصوتية والمرئية والتفريغات النصية المعتمدة لكبار العلماء الربانيين. تم تصميم التطبيق ليوفر تجربة استخدام فائقة السلاسة تراعي الهوية الإسلامية الأصيلة والزخارف الهندسية الراقية، دون أي صور لذوات الأرواح.

---

## ✨ أبرز مميزات التطبيق

* 📚 **مكتبة علمية منظمة:**
  تصفح الشروحات العلمية بدقة حسب المتون والأقسام العلمية (العقيدة، الفقه، الحديث، أصول الفقه، علوم القرآن، النحو واللغة)، أو الاستعراض المباشر وفق أسماء الشيوخ والعلماء مع سيرهم الذاتية وتصنيف مؤلفاتهم.

* 🎧 **مشغل صوتي متقدم:**
  إدارة كاملة للاستماع: إمكانية تسريع وإبطاء الصوت (من `0.75x` حتى `2.0x`)، ميزة **تخطي الصمت التلقائي** لاختصار زمن الدرس، ومؤقت النوم (Sleep Timer) مع تقديم وتأخير فوري (5 ثوانٍ)، بالإضافة إلى مشغل مصغر عائم (Mini-Player) للاستماع أثناء تصفح كامل شاشات التطبيق.

* 🎬 **مشاهدة مرئية مدمجة:**
  إمكانية التبديل اللحظي بنقرة زر بين وضع الاستماع الصوتي ووضع الفيديو لمتابعة المحاضرات المرئية بدقة عالية داخل مشغل التطبيق المدمج، أو الانتقال المباشر للمشاهدة على تطبيق يوتيوب.

* 📝 **التفريغ النصي الذكي:**
  قراءة تفريغ الدروس بخط عربي أميري أنيق ومريح للعين، مع تحكم فوري بحجم الخط، والبحث الفوري داخل نصوص الدروس مع تظليل النتائج، وزر مباشر للمساهمة في تفريغ الدروس الجديدة عبر واتساب.

* 📥 **الاستماع بدون إنترنت:**
  تحميل الدروس الصوتية وحفظها محلياً في الذاكرة مع تنظيمها التلقائي حسب الشرح والمتن، للاستماع في كل وقت دون الحاجة للاتصال بالشبكة.

* 📊 **متابعة الإنجاز والمحفوظات:**
  إضافة المتون والشروحات لقائمة الدراسة الخاصة، وحفظ تقدم الطالب في الدروس، مع توفير مؤشرات تقدم دقيقة وشاشة إحصائيات تفاعلية ترصد الدروس المنجزة وساعات الاستماع.

* 🔔 **نظام إشعارات وتحديثات فوري:**
  استقبال إشعارات وتنبيهات لحظية في الوقت الفعلي عبر السحابة فور إضافة شيوخ جدد، أو شروحات وتفريغات جديدة، بجانب نظام إشعار وتحديث ذكي لتثبيت الإصدارات الأحدث للتطبيق بسهولة.
